# Client Portal Starter

Client Portal Starter is a reusable member dashboard template for SaaS products.

It uses mock data only and is designed as a clean public portfolio asset.

## Included Screens

- Workspace overview
- Usage summary
- Saved work history
- Profile readiness
- Billing status mock
- Account settings mock

## Local Preview

Open `index.html` in a browser.

## Safety Check

Run:

```bash
npm run check
```

The check scans for private product names, common secret patterns, and accidental environment files.
